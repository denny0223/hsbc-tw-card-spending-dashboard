純前端靜態頁面，適合公開部署；沒有內嵌任何真實交易資料。
可一次上傳多個月份 JSON，彙整分析支出、用途、海外/國內、店家與時間軸。
支援的原始格式：[ ... ] 或 { "payload": [ ... ] }，每筆至少含 txnDate / description / ntdAmount。
